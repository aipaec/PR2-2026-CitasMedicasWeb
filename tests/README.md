# Pruebas

Esta carpeta está reservada para las pruebas automatizadas de OSCORP Medical.

No se encontró una suite de pruebas en el repositorio durante la revisión. Cuando se publique el código .NET, crear proyectos de pruebas compatibles con la versión real del SDK.

Cobertura recomendada:
- Validación de datos de usuarios y roles.
- Disponibilidad y no duplicación de horarios.
- Creación, cancelación y cambio de estado de citas.
- Relaciones entre citas, comprobantes, tratamientos y medicamentos.
- Autorización de operaciones por rol.

Registrar comandos de ejecución y resultados reales cuando existan pruebas.
