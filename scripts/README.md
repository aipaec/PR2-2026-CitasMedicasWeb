# Scripts auxiliares

Esta carpeta puede contener scripts repetibles para tareas de desarrollo, inicialización, validación o mantenimiento.

Antes de añadir un script:
- Explicar su propósito y parámetros.
- Indicar los permisos que necesita.
- Evitar credenciales incrustadas.
- Probarlo en un entorno no productivo.
- Advertir si modifica o elimina datos.

El script SQL principal de la base de datos permanece en `database/` y no se mueve.
