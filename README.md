## OSCORP Medical

Sistema Web de Agendamiento de Citas Médicas

## 1. Descripción del proyecto

OSCORP Medical es un sistema web orientado a la gestión y reserva de citas médicas. Busca facilitar la organización de turnos entre pacientes y médicos.

## 2. Problema que resuelve

La programación de citas médicas puede presentar dificultades y tiempos de espera prolongados. El proyecto busca mejorar la organización de los turnos y facilitar su administración.

## 3. Objetivo general y alcance

Desarrollar un producto mínimo viable (MVP) en entorno web para gestionar pacientes, médicos, especialidades y programación de citas médicas.
