# PR2-2026-CitasMedicasWeb

## 📋 Descripción del Proyecto
Sistema web para la gestión, reserva y administración de citas médicas.

## 🎯 Problema que Resuelve
Dificultad y tiempos de espera prolongados en la programación de citas médicas, optimizando la asignación de turnos entre pacientes y médicos.

## 🚀 Objetivo General y Alcance (MVP)
Desarrollar un producto mínimo viable (MVP) en entorno web para la gestión de pacientes, médicos, especialidades y programación de citas médicas.
