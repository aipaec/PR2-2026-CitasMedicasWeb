# Política de seguridad

## Reportar una vulnerabilidad

No publiques detalles explotables, credenciales ni datos personales en Issues públicos.

Para informar un problema de seguridad, contacta directamente a los responsables del repositorio mediante los canales privados disponibles en GitHub. Incluye una descripción, pasos para reproducirlo, impacto estimado y, si es posible, una propuesta de mitigación.

## Reglas para el proyecto
- Nunca subir contraseñas reales, tokens, claves API ni cadenas de conexión con credenciales.
- Mantener secretos fuera del control de versiones; usar variables de entorno o mecanismos seguros de configuración.
- No usar datos médicos reales en pruebas, capturas o ejemplos.
- Las cuentas de demostración y contraseñas de ejemplo deben ser ficticias y cambiarse antes de cualquier despliegue.
- Revisar las dependencias y actualizar las versiones vulnerables.
- No exponer mensajes de error internos ni información sensible al usuario final.

## Alcance y estado

OSCORP Medical es un proyecto académico en desarrollo. Este documento establece pautas para el repositorio; no constituye una certificación ni una auditoría de seguridad.
