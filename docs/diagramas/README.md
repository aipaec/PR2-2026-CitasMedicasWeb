# Diagramas del sistema

Guardar en esta carpeta los diagramas vigentes del proyecto, preferentemente en formato editable y también en un formato de visualización común (PNG o SVG).

Diagramas recomendados:
- Modelo entidad-relación, coherente con `database/script_oscorp_db.sql`.
- Casos de uso por tipo de usuario.
- Arquitectura lógica y despliegue, cuando se confirme la implementación.
- Diagramas de actividades o secuencia para reservar y cancelar citas.

Convención sugerida: `nombre-del-diagrama.ext`. Indicar fecha o versión en el documento cuando el diagrama cambie.

Actualmente esta carpeta contiene la documentación del modelo entidad-relación del sistema OSCORP, publicada en formato PDF. Este documento debe mantenerse actualizado y coherente con el script de la base de datos ubicado en `database/script_oscorp_db.sql`.
