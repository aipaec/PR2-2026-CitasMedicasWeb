# Planificación del proyecto OSCORP Medical

## 1. Descripción

La planificación del proyecto OSCORP Medical establece las actividades necesarias para desarrollar el sistema web de agendamiento de citas médicas. El cronograma tiene una duración tentativa de ocho semanas y puede ajustarse según el avance real del equipo.

## 2. Cronograma de actividades

| Fase / Actividad | Responsable | Semanas |
|---|---|---|
| Recolección de requisitos | Todo el equipo | S1 - S2 |
| Diseño de base de datos | Jhoel | S2 - S3 |
| Diseño de vistas web | Yury | S2 - S4 |
| Programación de login y roles | Julio | S3 - S4 |
| Programación de reservas | Julio | S4 - S5 |
| Conexión con SQL Server | Julio / Jhoel | S4 - S5 |
| Comprobante PDF | Julio / Jhoel | S5 - S6 |
| Pruebas de funcionamiento | Todo el equipo | S6 - S7 |
| Correcciones y documentación | Todo el equipo | S7 - S8 |
| Entrega final | Todo el equipo | S8 |

## 3. Organización del trabajo

Cada integrante tiene responsabilidades dentro del desarrollo:

- **Jhoel:** diseño y trabajo relacionado con la base de datos.
- **Yury:** diseño de las vistas web.
- **Julio:** programación del inicio de sesión, roles y reservas.
- **Todo el equipo:** recolección de requisitos, pruebas, correcciones y entrega final.

## 4. Hitos del proyecto

Los siguientes hitos se identifican a partir del orden de actividades del cronograma:

1. Requisitos del sistema recopilados.
2. Diseños de base de datos y vistas web preparados.
3. Funciones principales de programación desarrolladas.
4. Conexión con SQL Server y comprobante PDF trabajados.
5. Pruebas y correcciones realizadas.
6. Documentación y entrega final.

## 5. Dependencias de las actividades

Como orientación para organizar el trabajo, se proponen estas dependencias:

- La recolección de requisitos sirve como base para el diseño del sistema.
- El diseño de la base de datos y las vistas web sirve de apoyo para la programación.
- La conexión con SQL Server es necesaria para trabajar con los datos del sistema.
- Las pruebas permiten identificar errores antes de realizar las correcciones.
- La documentación debe estar preparada antes de la entrega final.

Estas dependencias son una interpretación de la secuencia de trabajo; el diagrama original no las representa explícitamente.

## 6. Diagrama de Gantt

El diagrama de Gantt tentativo se encuentra en el archivo `planificacion.png` de esta carpeta. Representa gráficamente las actividades, sus responsables y las semanas estimadas.

## 7. Observación

Este cronograma es una planificación inicial. Las fechas y actividades pueden modificarse de acuerdo con el avance real del proyecto y los acuerdos del equipo.
