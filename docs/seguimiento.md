## Criterio para marcar una tarea como terminada

- El cambio está integrado en el repositorio.
- La documentación afectada está actualizada.
- Se ejecutaron las pruebas disponibles y se registró su resultado.
- Existe un enlace a commit, Pull Request o archivo que permita verificarlo.

## Revisión periódica

El equipo debe actualizar esta tabla al revisar el avance y relacionar cada tarea con un Issue de GitHub. No registrar porcentajes de avance sin evidencia.
