# Manuales

Esta carpeta está reservada para los manuales que se elaboren cuando exista una versión ejecutable y verificable de la aplicación.

Documentos recomendados:
- Manual de usuario para pacientes.
- Manual de usuario para doctores.
- Manual de administración.
- Manual técnico de instalación, configuración y mantenimiento.

Cada manual debe indicar la versión del sistema a la que corresponde e incluir capturas actuales. No describir pantallas o funciones que aún no estén implementadas.
